Computer networking is the practice of connecting interconnected computing devices so that they can share data, resources, and applications. Modern computer networks form the backbone of global digital communication, enabling everything from simple file sharing to distributed cloud architectures.

The Open Systems Interconnection (OSI) reference model categorizes network architecture into seven distinct abstraction layers: Physical, Data Link, Network, Transport, Session, Presentation, and Application. Each layer serves the layer above it while concealing implementation details of the lower layers. In practical implementations, the TCP/IP model is widely adopted, consolidating functionality into four layers: Network Access, Internet, Transport, and Application.

At the core of digital data transmission is packet switching. Rather than establishing a dedicated physical circuit between communication endpoints, packet switching breaks data streams into smaller blocks called packets. Each packet contains payload data along with header information specifying source address, destination address, sequence numbers, and error detection checksums. Packets travel independently across dynamic routes managed by network routers before being reassembled at the destination.

The Internet Protocol (IP) provides logical addressing across disparate physical networks. IPv4 uses 32-bit addresses formatted as four dot-separated octets, yielding approximately four billion unique addresses. Due to rapid expansion of connected devices, IPv6 was designed with 128-bit addresses to provide a vastly larger address space along with enhanced security features and simplified header processing.

Transport layer protocols such as Transmission Control Protocol (TCP) and User Datagram Protocol (UDP) manage end-to-end communication constraints. TCP guarantees reliable, ordered, and error-checked delivery of stream data between applications through three-way handshakes, sequence acknowledgments, sliding window flow control, and congestion avoidance algorithms. Conversely, UDP prioritizes low-latency execution without connection setup overhead, making it suitable for real-time video streaming, online gaming, and Domain Name System (DNS) queries.
